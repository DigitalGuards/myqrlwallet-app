# MyQRLWallet 1.4.1

## Changes

- Android: the wallet opens on Testnet v3 again. Android 1.3.0 to 1.4.0 showed "Update MyQRLWallet for Testnet v3" because the app's v3 compatibility object never reached qrlwallet.com. iOS was not affected.
- Android: the launcher icon mark sits inside the circle, and the Android 12+ splash shows the whole mark.
- Android Settings: the Device Login row reads "Unlock with fingerprint, face, or screen lock".
- No wallet migration is required. Wallet data, PIN fallback and Device Login settings are preserved.

## Device acceptance

On Android, update the existing installation. Cold start the app: the splash shows the complete block mark and the wallet opens past the lock screen to the home screen (no "Update MyQRLWallet for Testnet v3"). Check the launcher icon, Settings > Device Login wording, a send with the transaction PIN, and a dApp connection. On iOS nothing changes; 1.4.0 (35) stays current.
