# MyQRLWallet mobile 1.3.0

This update adds 64-byte QRL address support for Testnet v3 and identifies the updated native bridge to the hosted wallet. Wallet creation, seed backup and restoration use the dedicated Testnet v3 profile. Device Login credentials, encrypted seed backups, contacts and dApp connection history are isolated from earlier profiles.

Earlier encrypted wallet backups remain on the device. They are excluded from automatic v3 restoration because an earlier address cannot identify the corresponding 64-byte account. Import an existing recovery phrase or seed to derive its v3 address. Keep the app installed and preserve its data if the earlier encrypted backup is your only recovery copy. Automatic conversion of that backup is not included in this release.

Remove All Wallets explicitly removes both current and preserved earlier wallet data. Device authentication remains required when either profile previously enabled Device Login.

Backgrounding invalidates pending authentication and bridge authorization. Returning to the app starts a fresh authentication attempt. Full-width addresses are preserved through dApp connection history, seed persistence and native bridge messages; shortened display fingerprints include a middle segment.

The release includes regression coverage for address and network boundaries, profile isolation, interrupted authentication, document binding and destructive-removal authorization. Native-device checks and signed store builds are separate release acceptance steps.
