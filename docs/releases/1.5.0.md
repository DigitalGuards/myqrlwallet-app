# MyQRLWallet 1.5.0

## Changes

- The wallet ships inside the app. The app loads a reviewed copy of the web wallet that is pinned by commit and sha256 at build time, so a change to qrlwallet.com can no longer alter the code that holds your keys. Wallet updates now arrive through app updates.
- Platform upgrade to Expo SDK 57 and React Native 0.86. iOS 16.4 or later is required (was 15.1).
- dApps can request signatures over typed data that contains QRL 2.0 (QIP-55) addresses, using the QRL-SIGN-TYPED-v2 scheme.
- dApp approvals: the PIN field stays usable while Device Login is on, and a wrong Device Login PIN falls back to manual entry.
- Disconnecting a dApp from the banner on the home screen also moves it to Recent in Settings > dApps, marked Disconnected, including when the dApp closed the connection first.
- Settings always offers Remove All Wallets, which the wallet's credential recovery screen points to.
- Android: the back button closes open dialogs and moves the app to the background from the home screen.
- dApp pairings made with an earlier version are cleared on the first launch. Pair the dApp again.
- Wallet data, PIN fallback and Device Login settings are preserved.

## Device acceptance

Update an existing installation that holds a wallet. Unlock with Face ID or fingerprint and with the wallet PIN, open Settings, send a small amount, and lock the app by switching away. Pair zondscan.com/dapp-example by deep link and by QR scan, sign a message with Device Login on, sign typed data, disconnect from the home banner and confirm Settings > dApps lists it under Recent as Disconnected. Cold start the app from a qrlconnect:// link.
