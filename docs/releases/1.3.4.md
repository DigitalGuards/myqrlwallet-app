# MyQRLWallet 1.3.4

## Changes

- Fix the Device Login switch in Settings staying on after a successful Face ID. Settings prompts (turn off Device Login, Change PIN, Remove All Wallets) and the Device Login setup prompt now wait for iOS to hand the app back after the Face ID sheet closes, with the same 10 second window as unlock. A real background still cancels the action.
- A failed attempt to turn off Device Login now shows an alert. Pressing Cancel stays silent.
- Preserve existing wallet data, PIN fallback and Device Login settings. No wallet migration is required.

## Device acceptance

Update the existing installation and retain the wallet. In Settings, turn Device Login off with Face ID and confirm the switch turns off with the "Disabled" alert, then turn it back on. Repeat Change PIN and cancel at the PIN form. Cancel a Face ID prompt and confirm nothing changes. Return to the wallet tab afterwards and confirm it did not relock unexpectedly.

Distribution for this update is iOS TestFlight. Android and public App Store promotion are separate release actions.
