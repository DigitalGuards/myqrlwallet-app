# MyQRLWallet 1.5.1

## Changes

- Change PIN opens its form reliably after Face ID or fingerprint. When a PIN change cannot complete, the app now says so and the old PIN stays active.
- Wallets with five or more accounts can change their PIN. Seed backups are saved one at a time.
- A dApp pairing link opened while the wallet was in the background is kept when the wallet reloads or locks before you unlock it.
- dApp requests that arrive while the app is locked appear after you unlock.
- After a Face ID or fingerprint prompt in Settings, Device Login still signs dApp requests without asking for the PIN again.
- When the wallet returns to the foreground it checks that each dApp connection is still alive. A dApp that stays away for more than 90 seconds is disconnected and shows as Disconnected, so pair it again from the dApp.
- Settings has a Copy Diagnostics row that copies a short technical log for support. It never contains your PIN, seed, keys or pairing links.
- Wallet data, PIN fallback, Device Login settings and dApp pairings carry over from 1.5.0.

## Device acceptance

Update the 1.5.0 installation. In Settings run Change PIN several times with Face ID or fingerprint, and once with a wrong current PIN. Pair zondscan.com/dapp-example by deep link with the wallet closed and with it in the background, sign a message and typed data with Device Login on, lock the app while a request is pending and unlock, and disconnect from the home banner. Open Settings, Copy Diagnostics and check the copied text has no PIN, seed or pairing link.
