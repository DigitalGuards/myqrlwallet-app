# MyQRLWallet 1.4.0

## Changes

- New MyQRLWallet brand: the block omega app icon, a themed Android 13+ icon, and a new splash screen on a deep navy background.
- Native screens move to the QRL Blue palette: lock screen, PIN entry, loading screen, Settings, dApp connections and the QR scanner. Buttons on the blue fill use dark text for contrast.
- The wallet itself (served from qrlwallet.com) already carries the new look, Inter balances and the simplified home screen.
- No wallet migration is required. Wallet data, PIN fallback and Device Login settings are preserved.

## Device acceptance

Update the existing installation and retain the wallet. Check the home screen icon (and on Android 13+ the themed icon), the splash screen on cold start, the lock screen and PIN entry, Settings, and the dApp connections screen. Unlock with Face ID or fingerprint and confirm the wallet opens as before.
