# MyQRLWallet 1.4.2

## Changes

- Android: creating or importing a wallet works again. Android 1.4.1 lost its connection to the wallet on the first page change, so setting the transaction PIN failed with "The native app did not confirm secure wallet storage".
- Android: Device Login unlocks with the screen lock on phones without an enrolled fingerprint or face.
- iOS: no behaviour change.
- No wallet migration is required. Wallet data, PIN fallback and Device Login settings are preserved.

## Device acceptance

On Android, install and create or import a wallet, set the transaction PIN, send a small amount, lock the app by switching away, and unlock with the wallet PIN and with Device Login. Verified on an Android 17 emulator before release.
