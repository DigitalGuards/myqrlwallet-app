# MyQRLWallet 1.5.4

## Changes

- The bundled wallet is the November web release (frontend f137af3).
- New Theme setting: Dark, Light or Same as the phone. Until you choose, the app uses the phone's own appearance, and so does the launch screen. If you choose Dark on a phone that is set to light, the launch screen is still light for a moment before the dark app appears. The choice is in the app's Settings, under Display. The app's own screens (Settings, Connected dApps, PIN windows, QR scanner permission screen, loading and lock screens) and the wallet inside it follow it, and Same as the phone follows the phone's appearance while the app is open. Reset Session Data and Remove All Wallets keep your choice.
- Explorer links open ShorScan at shorscan.com, the explorer's new address. Links to zondscan.com from earlier versions still open.
- After a PIN unlock, dApp approvals and the wallet's own send, token and NFT screens check the request again before anything is signed or broadcast.
- A dApp request that fails answers the dApp with an error code that names the cause. Code 4001 now means only that you declined or dismissed the request.
- dApp connections use connect SDK 5.2.1.
- The wallet's Settings page has a new layout on the web. In the app, Settings opens the app's own settings screen; the new web page shows only when a settings link from outside opens it.
- The wallet's page title and its notice for retired app versions name the App Store listing.
- The iPhone app is built with Xcode 27 and the iOS 27 SDK, which Apple requires from April 2027, and adopts the scene life cycle that iOS 27 needs.
- Wallet data, PIN, Device Login settings, language and dApp pairings carry over from 1.5.3.

## Device acceptance

The full step list for both phones is the file "What to test on the phones". In short: update the 1.5.3 store installation, unlock with Face ID or fingerprint and with the wallet PIN, check the balance and history, send a small amount, open an explorer link from the history (it opens shorscan.com), walk every row of Settings including Theme, run Change PIN, switch the language and the theme and back, open the Address Book and Connected dApps, pair shorscan.com/dapp-example and sign a message. On iPhone open a pairing link with the app closed and with the app running. On Android press Back on each wallet page and at Home, and check the navigation bar in both themes. Settings shows Version 1.5.4 and Wallet build f137af3a8e65 (bundled).
