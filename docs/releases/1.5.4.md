# MyQRLWallet 1.5.4

## Changes

- The bundled wallet is the November web release (frontend a22117b).
- Explorer links open ShorScan at shorscan.com, the explorer's new address. Links to zondscan.com from earlier versions still open.
- After a PIN unlock, dApp approvals and the wallet's own send, token and NFT screens check the request again before anything is signed or broadcast.
- A dApp request that fails answers the dApp with an error code that names the cause. Code 4001 now means only that you declined or dismissed the request.
- dApp connections use connect SDK 5.2.1.
- The wallet's Settings page has a new layout on the web. In the app, Settings opens the app's own settings screen, which is unchanged; the new web page shows only when a settings link from outside opens it.
- The wallet's page title and its notice for retired app versions name the App Store listing.
- Wallet data, PIN, Device Login settings, language and dApp pairings carry over from 1.5.3.

## Device acceptance

Update the 1.5.3 store installation. Unlock with Face ID or fingerprint and with the wallet PIN, check the balance and history, send a small amount, and open an explorer link from the history: it opens shorscan.com. Walk every row of Settings, run Change PIN, switch the language and back, open the Address Book and Connected dApps and return. Pair shorscan.com/dapp-example and sign a message. On Android press Back on each wallet page and at Home. Settings shows Version 1.5.4 and Wallet build a22117b41e67 (bundled).
